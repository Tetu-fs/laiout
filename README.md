# laiout

A Skill that limits AI-driven UI implementation in frontend development to the minimum necessary.
Its goals are to avoid generating designs commonly referred to as “AI slop”, keep the AI’s reasoning focused on implementation rather than decoration, and ultimately leave design and styling to humans with their own intent and creative direction.

## What is this?

laiout is a Skill that guides AI to build UIs using basic layout principles, minimal spacing rules, and reuse of existing styles and components.
Decorative styling is generally avoided and is only applied when existing styles or components are available, or when explicitly requested.

## Usage

Add `SKILL.md` to your AI coding agent's Skill directory.

Project-specific components, CSS frameworks, design systems, and other rules can be added to the `Project-specific Rules` section.
