# laiout

A layout-focused AI Skill for frontend development.
The goal is to prevent formulaic visual patterns and generic designs commonly referred to as “AI slop,” to keep the AI’s valuable reasoning focused on layout and implementation rather than decoration, and ultimately to leave visual design and styling to humans with their own intent and creative direction.

## What is this?

laiout is a Skill that guides AI coding agents to create UI layouts
without making unnecessary visual design decisions.

It focuses on:

- Layout and information structure
- Spacing and alignment
- Responsive behavior
- Reusing existing components

It intentionally avoids unnecessary:

- Colors
- Borders
- Shadows
- Gradients
- Other visual decoration

The goal is to make AI-generated UI easier for humans to style and refine later.

## Usage

Add `SKILL.md` to your AI coding agent's Skill directory.

Project-specific components, frameworks, and design system rules can be added
to the `Project-specific Rules` section.
