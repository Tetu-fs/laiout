# laiout

フロントエンド開発におけるAIのUI実装を必要最小限に限定するスキルです。
AI Slopなデザインを発生させないこと、AIの思考リソースを装飾ではなく実装に使うこと、そして最終的に人間による意図や思想を持ったデザイン・スタイリングが行われることを目的としています。

## これは何？

laioutは、レイアウトの基本原則と最低限のスペーシングのルール、既存スタイルやコンポーネントの再利用のみでUIを構築するように指示するスキルです。
装飾的なスタイリングは原則行われず、既存のスタイルやコンポーネントがある場合、または明示的な指示がある場合のみ行われます。

## 使い方

`SKILL.md`をAIコーディングエージェントのSkillディレクトリに追加してください。

プロジェクト固有のコンポーネント、CSSフレームワーク、デザインシステムなどのルールは、`Project-specific Rules`セクションに追加できます。
