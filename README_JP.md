# laiout

フロントエンド開発向けの、レイアウトに特化したAI Skillです。
AI特有の装飾的なUIパターンや、いわゆる「AI Slop」と呼ばれる画一的なデザインを発生させないこと、AIの貴重な思考リソースを装飾ではなく機能に使うこと、そして最終的に人間による意図や思想を持ったデザイン・スタイリングが行われることを目的としています。

## これは何？

laioutは、AIコーディングエージェントに対して、不要な装飾やデザイン判断を行わず、UIのレイアウトを構築するよう指示するSkillです。

主に以下を扱います。

- レイアウトと情報構造
- 余白と整列
- レスポンシブ対応
- 既存コンポーネントの再利用

一方で、以下のような不要な装飾は意図的に避けます。

- 色
- Border
- Shadow
- Gradient
- その他の視覚的な装飾

AIが生成したUIに対して、人間が後から自由にデザインや装飾を追加・調整しやすくすることを目的としています。

## 使い方

`SKILL.md`をAIコーディングエージェントのSkillディレクトリに追加してください。

プロジェクト固有のコンポーネント、CSSフレームワーク、デザインシステムなどのルールは、`Project-specific Rules`セクションに追加できます。
